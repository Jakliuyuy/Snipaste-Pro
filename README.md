# Snipaste Pro（官方原版 + 截图实时翻译增强版）

本项目完美整合 **Snipaste 官方正版 v2.11.3 (x64) 原生二进制** 与自主研发的 **智能无感截图实时翻译伴侣**。彻底解决从零自绘重构带来的样式不一致、黑边或兼容性问题，为您提供 100% 官方纯正的 Snipaste 原生截屏、窗口探测、放大镜、全套标注及贴图体验，并深度注入无感快捷的实时翻译能力！

---

## 🌟 核心特性与架构

- **100% 官方正版原生体验**：采用官方 `Snipaste.exe` 原生 C++/Qt6 核心二进制。原汁原味的高性能像素标尺、八向拖拽吸附、放大镜取色器、高精度窗口/按钮层级探测以及全套矢量标注。
- **智能实时翻译伴侣**：
  - 支持 **Windows.Media.Ocr (WinRT 系统级硬件加速)** 与 **RapidOCR 离线 OCR**，毫秒级多语言文本识别。
  - 多引擎极速智能翻译（中英日韩德法俄等），免除复杂 API 申请配置。
  - **优雅现代毛玻璃翻译卡片**：自动悬浮于选区旁，支持分句原文/译文对照、一键复制全部文本。
  - **原位图片替换与一键贴出**：自动生成抹除原文字并自适应填入译文的高清翻译图，支持一键调用 Snipaste 贴图功能（Pin）将翻译图直接悬浮钉在桌面上！
- **原生无感静默启动器 (`SnipastePro.exe`)**：
  - 基于 C 语言 Win32 API 编译的原生引导程序，无控制台黑框、无内存常驻冗余，一键同时拉起官方 Snipaste 与实时翻译伴侣。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 | 核心亮点 |
| :--- | :--- | :--- |
| **`F1`** | **Snipaste 原生官方截屏** | 官方正版 100% 原生体验，支持智能窗口探测、放大镜取色(`C`)、全套矢量标注 |
| **`Alt + T`** 或 **`F2`** | **截屏并实时翻译** | 唤起官方截屏框选目标文本，选定完成后自动弹出悬浮翻译卡片 |
| **`F3`** | **贴图 (Pin)** | 将剪贴板图片或文本固定在屏幕顶层，支持缩放/旋转/透明度 |
| **`F4`** | **鼠标穿透** | 切换所有贴图的鼠标点击穿透模式 |

## 🚀 快速上手与开箱即用

### 方式一：下载预编译便携完整包（推荐）

1. 前往 GitHub Releases 下载 **`Snipaste-v2.11.3-Windows-x64.zip`**。
2. 解压至任意目录（建议无空格英文路径）。
3. 双击运行目录下的 **`SnipastePro.exe`**（或 `启动.bat`）即可！
   - 系统右下角托盘将显示官方 Snipaste 图标；
   - 按下 `Alt + T` 或 `F2` 即可截屏并实时翻译，按下 `F1` 享受原生官方截屏。

### 方式二：从源码运行与二次开发

1. **环境要求**：
   - Windows 10 / 11 64位
   - Python 3.10+
2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
3. **启动伴侣**：
   ```bash
   python translator/main.py
   ```
4. **编译原生启动器**（需 MinGW gcc）：
   ```bash
   x86_64-w64-mingw32-gcc -mwindows -O2 -s launcher/launcher.c -o SnipastePro.exe
   ```

## 📁 目录结构

```text
Snipaste-v2.11.3-Windows-x64/
├── SnipastePro.exe          # 原生 C 语言静默启动引导器（主入口）
├── 启动.bat                 # 备用批处理启动脚本
├── Snipaste.exe             # 官方正版 Snipaste v2.11.3 核心程序
├── Qt6*.dll                 # 官方原版运行依赖库
├── translator/              # 实时翻译伴侣核心模块

│   ├── bridge.py            # Snipaste CLI 交互与全局热键监听
│   ├── ocr_worker.py        # 离线 OCR 与多后端翻译引擎
│   └── ui_card.py           # 悬浮毛玻璃双语对照卡片 & 原位译图生成
├── runtime/                 # 开箱即用内置 Python 运行环境
└── README.md                # 使用与配置文档
```
