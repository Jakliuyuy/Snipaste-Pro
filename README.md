# Snipaste 全功能重构版（集成截图实时翻译）

本项目基于 **REA (Reverse Engineer Anything)** 对官方 **Snipaste v2.11.3 (x64)** 进行深度逆向分析，完全还原了其底层架构、交互逻辑、Win32 边界探测机制及所有标注、贴图功能，并创新性地研发集成了 **截图实时翻译（RapidOCR 离线文字识别 + 极速多引擎翻译）** 功能。

---

| 功能模块 | 官方 Snipaste 功能 | 本重构版本实现 | 增强特性 |
| :--- | :--- | :--- | :--- |
| **基础截屏** | `F1` 快捷键全屏覆盖、框选截图 | `F1` 全屏与跨多显示器高精度截图 | 实时准星与像素标尺 |

## 二、截图实时翻译功能说明

在选区完成后，按下快捷键 `T` 或点击工具栏上的 **🌐 翻译** 图标：

1. **原位替换模式 (In-place Replacement)**：
   - 自动擦除原图中的外文字符，并在原位置自适应字体排版绘制译文，生成完全翻译后的图像。
2. **悬浮对照卡片 (Floating Card)**：
   - 并在选区旁弹出优雅毛玻璃半透明对照窗，分段列出原文与译文。
   - 支持一键复制全部译文、单句复制、切换目标语种。
3. **支持引擎**：
   - 内置极速网络翻译后端（免 API Key，开箱即用）。
   - 支持自定义接入 OpenAI、DeepSeek 等大模型 API。

## 三、快捷键一览

- `F1`：开始截图（或右键托盘图标点击截图）
- `F3`：将截图或剪贴板内容（图片/文本）贴到屏幕上
- `F4`：开启/取消所有贴图窗口的鼠标穿透模式
- `Ctrl + F1`：快速全屏截图并复制到剪贴板
- 截图选区中：
  - `T`：启动选区实时翻译
  - `Enter` / `Ctrl + C` / 双击：完成截图并复制到剪贴板
  - `Ctrl + S`：保存为图片文件
  - `C`（未开始框选时）：一键复制光标所在像素的颜色值
  - `Shift`（未开始框选时）：切换颜色值格式（HEX ↔ RGB ↔ HSL）
  - 方向键 `↑ ↓ ← →`：像素级微调选区（按住 `Shift` 10 像素步进）
  - `Esc` / 鼠标右键：取消/退出截图

## 四、安装与运行

### 1. 环境要求
- Python 3.10+
- 推荐操作系统：Windows 10 / Windows 11（同样兼容 Linux / macOS）

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动应用
```bash
python main.py
```

### 4. 打包为 Windows 单文件 .exe
在 Windows 终端中运行：
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --icon=snipaste/assets/icon.ico --name=SnipastePro main.py
```
生成的 `SnipastePro.exe` 位于 `dist/` 目录中，支持免安装纯绿色运行。
